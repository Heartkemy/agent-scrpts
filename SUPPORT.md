# Support

For usage questions and reproducible non-security bugs, use the
[GitHub issue tracker](https://github.com/Heartkemy/agent-scrpts/issues). Include
the Node version, operating system, minimal reproduction, expected result, and
actual result.

Do not include tokens, local paths, private task content, model weights, or
security-sensitive details in an issue. For vulnerabilities, follow
[SECURITY.md](SECURITY.md).
